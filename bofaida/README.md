# موقع BOFAIDA ADS — تشغيل وتعديل

موقع تعريفي من صفحة واحدة لوكالة **BOFAIDA ADS**. الملف مستقلّ بالكامل: التنسيق
والسكربت داخل `index.html`، فلا يحتاج بناءً ولا حزماً.

## التشغيل محلياً

```bash
npm run bofaida
```

يطبع رابطين: واحد لهذا الجهاز، وواحد للشبكة تفتحه من الهاتف. للإيقاف: `Ctrl + C`.

## ما ينبغي أن تراجعه بنفسك

بُني الموقع بمعلومتين مفترضتين — إن كانتا خطأً فتغييرهما سطرٌ واحد:

| المعلومة | القيمة الحالية | أين تُغيَّر |
| --- | --- | --- |
| الهاتف والواتساب | `+213 673 232 932` | ابحث في `index.html` عن `213673232932` — يظهر في خمسة روابط وفي نصّ واحد |
| المدينة | تيمياوين وبرج باجي مختار | قسم «اتصل بنا» والتذييل ووسم `description` |

وقسم **«نماذج»** يعرض أنواع الأعمال لا صوراً حقيقية. حين تصل صور أعمال منجزة،
تُستبدل بها البطاقات الأربع بأسماء أصحابها.

## الأيقونات

```bash
pip install pillow
python3 bofaida/icons/generate-icons.py
```

يكتب `icon-192.png` و`icon-512.png` و`icon-maskable-512.png` و`apple-touch-icon.png`.
الرمز مكبّر صوت بموجتين — بلا نصّ حتى يبقى واضحاً في الأحجام الصغيرة.

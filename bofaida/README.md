# موقع BOFAIDA ADS — تشغيل وتعديل

موقع تعريفي من صفحة واحدة لـ**BOFAIDA ADS** — فيديوهات إعلانية للمنتجات التجارية
تُصنع بالذكاء الاصطناعي. الملف مستقلّ بالكامل: التنسيق والسكربت داخل `index.html`،
فلا يحتاج بناءً ولا حزماً.

## التشغيل محلياً

```bash
npm run bofaida
```

يطبع رابطين: واحد لهذا الجهاز، وواحد للشبكة تفتحه من الهاتف. للإيقاف: `Ctrl + C`.

## المعلومات الثابتة وأين تُغيَّر

| المعلومة | القيمة | أين |
| --- | --- | --- |
| الهاتف والواتساب | `0673 23 29 32` | ابحث في `index.html` عن `213673232932` (خمسة روابط) وعن `0673 23 29 32` (النصّ المعروض) |
| المدينة | برج باجي مختار | قسم «اتصل بنا» والتذييل ووسم `description` |

وقسم **«نماذج»** يعرض أنواع الأعمال لا فيديوهات حقيقية — لأن الوكالة جديدة ولا
نماذج لها بعد. حين يُنجز أوّل فيديو، تُستبدل به إحدى البطاقات الأربع.

**ما لم يُكتب في الموقع عمداً: السعر.** الموقع يقول «في متناول الجميع» ولا يذكر رقماً،
فالرقم المكتوب على صفحة يصير وعداً يصعب التراجع عنه. حين تستقرّ أسعارك، يُضاف قسم
أسعار بثلاث باقات — وهو عمل ساعة.

## الأيقونات

```bash
pip install pillow
python3 bofaida/icons/generate-icons.py
```

يكتب `icon-192.png` و`icon-512.png` و`icon-maskable-512.png` و`apple-touch-icon.png`.
الرمز مثلّث تشغيل داخل إطار وشرارة إلى جانبه — بلا نصّ حتى يبقى واضحاً في الأحجام
الصغيرة.

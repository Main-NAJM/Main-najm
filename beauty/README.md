# أم آية — متجر أدوات التجميل واكسسوارات الهواتف

متجر من صفحة واحدة (`index.html`) يعرض قسمين: **مجموعة التجميل** و**اكسسوارات الهواتف
الذكية**، ويستقبل الطلبات عبر واتساب. الملف مستقلّ بالكامل: التنسيق والسكربت والبيانات
داخله، ولا يحتاج بناءً ولا حزماً ولا أي مكتبة خارجية.

| ما يقدّمه | التفصيل |
| --- | --- |
| قسم التجميل | شبكة بطاقات من `PRODUCTS`، مع تصفية حسب الفئة |
| قسم اكسسوارات الهواتف | شبكة مستقلّة من `PHONE`، بهويّة لونية فيروزية تميّزها |
| سلة طلب | تجمع من القسمين معاً، تُحفظ في المتصفّح، وتُرسل طلباً واحداً مُفصّلاً |
| فيديوهات | إطارات تيك توك وانستقرام، وتمهيد أنيق مكان الفيديو قبل إضافته |
| شريط ضمانات | التوصيل والدفع عند الاستلام والأصالة والرد السريع |

> اسم المجلّد والرابط `beauty` كما هما عمداً حتى لا ينكسر رابط سبق أن شاركتِه. لتغييره إلى
> `om-aya` مثلاً: بدّلي اسم المجلّد، و`DEST_DIR` في `copy-to-dist.mjs`، والمسار في
> `firebase.json` و`package.json`.

## التعديل — أين تغيّرين ماذا

كل ما يخصّ متجرك في أعلى وسم `<script>` داخل `index.html`، تحت العنوان **«بيانات المتجر»**.
ما بعده لا يحتاج تعديلاً.

### 1. اسم المتجر وبيانات التواصل

```js
const STORE = {
  brand: 'أم آية',            // يظهر في العنوان ورسالة الطلب والتذييل
  phone: '213696847079',      // أرقام فقط، مع رمز الدولة وبدون +
  instagram: 'https://www.instagram.com/am_aya_x',
  tiktok: 'https://www.tiktok.com/@am_aya_x',
  handle: '@am_aya_x',        // يظهر في الترويسة والشريط المتحرّك والتذييل
  currency: 'د.ج',
};
```

أيّ حقل تتركينه فارغاً يختفي زرّه من الموقع بدل أن يظهر رابطاً معطوباً. وإن نقص ما يكسر
الطلب فعلاً (الرقم أو الروابط) ظهر تنبيه أصفر أعلى الصفحة، ويختفي وحده بعد ضبطه.

> اسم المتجر مكتوب أيضاً في وسم `<title>` ووسوم `meta` أعلى الملف وفي الترويسة والتذييل —
> غيّريه هناك كذلك إن بدّلتِ `brand`.

### 2. الشريط المتحرّك

```js
const TICKER = ['توصيل لكل ولايات الوطن', 'الدفع عند الاستلام', 'منتجات أصلية', 'جديد كل أسبوع'];
```

يُضاف معرّفك `handle` في آخر القائمة تلقائياً.

### 3. المنتجات — قائمتان بنفس الحقول

`PRODUCTS` لمنتجات التجميل، و`PHONE` لاكسسوارات الهواتف. الحقول واحدة في القائمتين:

```js
{ id:'matte-lip',                      // معرّف فريد لا يتكرّر في القائمتين معاً
  name:'أحمر شفاه مطفي طويل الثبات',
  category:'شفاه',                      // تُصبح زرّ تصفية، ولها تدرّجها اللوني
  price:1600,                           // رقم فقط، بلا عملة ولا فواصل
  was:2100,                             // السعر قبل التخفيض — يُظهر شارة «خصم ٪»، أو 0
  badge:'',                             // شارة نصّية مثل 'جديد'، أو اتركيها فارغة
  glyph:'lipstick',                     // الرسم الظاهر مكان الصورة
  image:'',                             // رابط صورة المنتج — يحلّ محلّ الرسم عند وجوده
  tiktok:'', instagram:'' }             // رابط فيديو المنتج على المنصّة (اختياري)
```

**الرسوم المتاحة لـ `glyph`:**

| للتجميل | لاكسسوارات الهواتف |
| --- | --- |
| `lipstick` أحمر شفاه · `polish` طلاء أظافر · `cream` كريم أو سيروم · `eye` عيون · `gem` مجوهرات · `brush` فرش | `phone` غطاء هاتف · `ring` حامل حلقي · `earbuds` سمّاعات · `powerbank` شاحن متنقّل · `carmount` حامل سيارة · `strap` خيط تعليق · `cable` كابل شحن · `ringlight` حلقة إضاءة |

**لون البطاقة يأتي من الفئة** لا من المنتج: لكل فئة تدرّجها في `GRADIENTS` أسفل السكربت.
فئة جديدة بلا تدرّج تأخذ الوردي الافتراضي — أضيفي لها سطراً هناك لتأخذ لونها الخاص.

لإضافة منتج: انسخي سطراً كاملاً وغيّري بياناته، واحرصي أن يكون `id` مختلفاً عن كل
المعرّفات في القائمتين. عند حذف منتج تُسقطه السلة المحفوظة تلقائياً من سلال الزائرات
القديمة.

> **الأسعار المكتوبة الآن تقديرية** — بدّليها بأسعارك الحقيقية قبل النشر.

> **الصور:** الرسوم الخطّية مكان مؤقّت ريثما تُصوَّر المنتجات. ضعي الصور في
> `beauty/images/` واكتبي `image: './images/matte-lip.jpg'`، أو استخدمي رابطاً خارجياً
> كاملاً. المقاس المناسب مربّع (1:1) وعرض 800 بكسل تقريباً. الصورة تُغني عن `glyph`.

### 4. الفيديوهات

```js
const VIDEOS = [
  { platform:'tiktok',                        // 'tiktok' أو 'instagram'
    embedId:'7412345678901234567',            // معرّف الفيديو فقط
    url:'https://www.tiktok.com/@am_aya_x/video/7412345678901234567',
    title:'أحمر الشفاه المطفي — النتيجة على الطبيعة',
    text:'لون واحد، ثلاث إطلالات، وثبات طول اليوم.' },
];
```

**من أين يأتي `embedId`؟** من رابط الفيديو نفسه:

| المنصّة | الرابط | المعرّف |
| --- | --- | --- |
| تيك توك | `https://www.tiktok.com/@am_aya_x/video/`**`7412345678901234567`** | الأرقام في آخره |
| انستقرام | `https://www.instagram.com/reel/`**`Cx1y2Z3aBcD`**`/` | الرمز بعد `reel/` |

ما دام `embedId` فارغاً يظهر مكان الفيديو تمهيد بلون الموقع بدل إطار معطوب، ويبقى زرّ
«شاهدي على…» يفتح حسابك على المنصّة. وإن تركتِ `url` فارغاً فتح الزرّ الحساب كذلك.

## التشغيل محلياً

من جذر المستودع:

```bash
npm run beauty
```

أو مباشرة (يحتاج Node.js 18 أو أحدث فقط):

```bash
node beauty/serve.mjs
```

يطبع الأمر رابطين:

```
على هذا الجهاز:   http://localhost:8081
على الشبكة:        http://192.168.x.x:8081
```

- **رابط الجهاز** — افتحيه في متصفّح الحاسوب نفسه.
- **رابط الشبكة** — افتحيه من هاتفك أو من أي جهاز على نفس شبكة الواي‑فاي، لتجربة الموقع
  كما تراه زبونتك قبل نشره.

لتغيير المنفذ إن كان مشغولاً: `npm run beauty -- 3000`. وإن كان المطلوب مشغولاً يجرّب
الخادم المنفذ التالي تلقائياً. للإيقاف: `Ctrl + C`.

بديل سريع بلا Node.js: افتحي `beauty/index.html` بالمتصفّح مباشرة — يعمل العرض، لكنك لن
تحصلي على رابط يفتح من الهاتف.

## النشر

المتجر يُنشر مع باقي المشروع على Firebase Hosting، على المسار `/beauty`:

| العنوان | المحتوى |
| --- | --- |
| `https://<اسم-المشروع>.web.app/` | تطبيق حرفة برو |
| `https://<اسم-المشروع>.web.app/albacha` | موقع مؤسسة الباشة للمعادن |
| `https://<اسم-المشروع>.web.app/beauty` | متجر أم آية |

`npm run build` ينسخ محتوى هذا المجلد تلقائياً إلى `dist/beauty` عبر `copy-to-dist.mjs`،
و`firebase.json` يحوي إعادة توجيه `/beauty` ← `/beauty/index.html`. ثم:

```bash
npm run deploy
```

تفاصيل إعداد Firebase والنشر عبر GitHub Actions في [`site/README.md`](../site/README.md) —
الإعداد نفسه يخدم المواقع الثلاثة.

### لجعل المتجر في جذر النطاق بدل `/beauty`

في `beauty/copy-to-dist.mjs` اجعلي `DEST_DIR = ''`، واحذفي إعادة توجيه `/beauty` من
`firebase.json`.

## التصميم

| العنصر | الاختيار |
| --- | --- |
| الخطّ | **Readex Pro** وحده، عربيّه ولاتينيّه، بأوزان 200 إلى 700 |
| الألوان | فوشي `#EC4899` وبنفسجي `#8B5CF6` وفيروزي `#22D3EE` على برقوقي داكن `#1A0512` أو وردي فاتح `#FFF5FA` |
| البطاقات | تدرّج لوني لكل فئة، وهالة ملوّنة عند مرور المؤشّر |
| الأيقونات | رسوم خطّية داخل الملف — لا رموز تعبيرية، فتبقى متّسقة وتقبل التلوين |
| الحركة | كرات ضبابية متحرّكة في الواجهة، ظهور تدريجي عند التمرير، وشريط علوي متحرّك |

نصّ الأزرار الملوّنة **برقوقي داكن لا أبيض**: الأبيض على الفوشي الفاتح لا يبلغ حدّ
التباين المطلوب، والداكن يبلغه ويبقي اللون صارخاً. وكلّ الحركة تحترم
`prefers-reduced-motion`: من يوقفها في إعدادات جهازه يرى الموقع ثابتاً.

## ملاحظات

- **الطلبات تصل عبر واتساب فقط.** لا يوجد خادم ولا قاعدة بيانات: زرّ «إتمام الطلب» يفتح
  واتساب برسالة جاهزة فيها المنتجات والكميات والإجمالي، وتحتها حقول فارغة للاسم والولاية
  ورقم الهاتف تملؤها الزبونة قبل الإرسال.
- **رسوم التوصيل ليست في الإجمالي** — مكتوب ذلك في السلة، وتُتّفق عليها في المحادثة حسب
  الولاية.
- **السلة محفوظة في متصفّح الزائرة** (`localStorage`)، فلا تصل إليكِ ولا تُشارَك بين
  الأجهزة. في التصفّح الخاص قد يمنع المتصفّح الحفظ، فتعمل السلة في الذاكرة حتى إغلاق
  الصفحة — وهذا متوقّع.
- **الخطّ يُحمَّل من Google Fonts**، فبدون إنترنت يعمل الموقع بخطّ النظام الاحتياطي.
- **إطارات تيك توك وانستقرام** تُحمَّل من المنصّتين، وقد لا تظهر إن كان الفيديو خاصاً أو
  محذوفاً أو كان المتصفّح يحجب المحتوى الخارجي. زرّ «شاهدي على…» يبقى بديلاً يعمل دائماً.
- **تثبيت المتجر كتطبيق (PWA)** غير مُهيّأ هنا. لإضافته انسخي `manifest.webmanifest`
  و`sw.js` و`icons/` من مجلد `site/` وعدّلي الأسماء والألوان — الطريقة موصوفة في
  [`site/README.md`](../site/README.md).

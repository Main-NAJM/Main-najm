# متجر الجمال — موقع أدوات التجميل والاكسسوارات

متجر من صفحة واحدة (`index.html`) لعرض أدوات التجميل والاكسسوارات النسائية واستقبال الطلبات
عبر واتساب. الملف مستقلّ بالكامل: التنسيق والسكربت والبيانات داخله، ولا يحتاج بناءً ولا حزماً.

| ما يقدّمه | التفصيل |
| --- | --- |
| عرض المنتجات | شبكة بطاقات تُبنى من مصفوفة `PRODUCTS` أعلى السكربت |
| سلة طلب | تُحفظ في المتصفّح، وتُرسل كطلب واحد مُفصّل على واتساب |
| فيديوهات | إطارات تيك توك وانستقرام، وتمهيد أنيق مكان الفيديو قبل إضافته |
| تواصل | أزرار واتساب وانستقرام وتيك توك تُبنى من إعداد واحد |

## الإعداد — ثلاث خطوات

كل ما يخصّ متجرك في أعلى وسم `<script>` داخل `index.html`، تحت العنوان
**«بيانات المتجر»**. ما بعده لا يحتاج تعديلاً.

### 1. بيانات التواصل

```js
const STORE = {
  phone: '966512345678',                          // أرقام فقط، مع رمز الدولة وبدون +
  instagram: 'https://www.instagram.com/حسابك',
  tiktok: 'https://www.tiktok.com/@حسابك',
  currency: 'ر.س',
};
```

أيّ حقل تتركينه فارغاً يختفي زرّه من الموقع بدل أن يظهر رابطاً معطوباً. وما دام شيء منها
غير مضبوط يظهر لكِ تنبيه أصفر أعلى الصفحة يذكّرك بما ينقص — ويختفي وحده بعد ضبطه.

### 2. المنتجات

```js
const PRODUCTS = [
  {
    id: 'lipstick',                  // معرّف فريد لا يتكرّر (يُستخدم في السلة)
    name: 'أحمر الشفاه الفاخر',
    category: 'أحمر شفاه',
    price: 89,                       // رقم فقط، بلا عملة
    emoji: '💄',                     // يظهر مكان الصورة ريثما تُصوَّر المنتجات
    image: '',                       // رابط صورة المنتج — يحلّ محلّ الرمز عند وجوده
    tiktok: '',                      // رابط فيديو المنتج على تيك توك (اختياري)
    instagram: '',                   // رابط فيديو المنتج على انستقرام (اختياري)
  },
];
```

لإضافة منتج: انسخي عنصراً كاملاً وغيّري بياناته، واحرصي أن يكون `id` مختلفاً عن البقية.
عند حذف منتج تُسقطه السلة المحفوظة تلقائياً من طلبات الزائرات القديمة.

> **الصور:** ضعي ملفات الصور في `beauty/images/` واكتبي `image: './images/lipstick.jpg'`،
> أو استخدمي رابطاً خارجياً كاملاً. المقاس المناسب 4:3 وعرض 800 بكسل تقريباً.

### 3. الفيديوهات

```js
const VIDEOS = [
  {
    platform: 'tiktok',              // 'tiktok' أو 'instagram'
    embedId: '7412345678901234567',  // معرّف الفيديو فقط
    url: 'https://www.tiktok.com/@حسابك/video/7412345678901234567',
    title: 'أحمر الشفاه الفاخر — النتيجة على الطبيعة',
    text: 'شاهدي الفرق الذي يصنعه أحمر الشفاه الفاخر على إطلالتكِ.',
  },
];
```

**من أين يأتي `embedId`؟** من رابط الفيديو نفسه:

| المنصّة | الرابط | المعرّف |
| --- | --- | --- |
| تيك توك | `https://www.tiktok.com/@حسابك/video/`**`7412345678901234567`** | الأرقام في آخره |
| انستقرام | `https://www.instagram.com/reel/`**`Cx1y2Z3aBcD`**`/` | الرمز بعد `reel/` |

ما دام `embedId` فارغاً يظهر مكان الفيديو تمهيد بلون الموقع بدل إطار معطوب، ويبقى زرّ
«شاهدي على…» يفتح حسابك على المنصّة.

## التشغيل محلياً

من جذر المستودع:

```bash
npm run beauty
```

أو مباشرة (يحتاج Node.js 18 أو أحدث فقط):

```bash
node beauty/serve.mjs
```

يطبع الأمر رابطين:

```
على هذا الجهاز:   http://localhost:8081
على الشبكة:        http://192.168.x.x:8081
```

- **رابط الجهاز** — افتحيه في متصفّح الحاسوب نفسه.
- **رابط الشبكة** — افتحيه من هاتفك أو من أي جهاز على نفس شبكة الواي‑فاي، لتجربة الموقع
  كما تراه زبونتك قبل نشره.

لتغيير المنفذ إن كان مشغولاً: `npm run beauty -- 3000`. وإن كان المطلوب مشغولاً يجرّب
الخادم المنفذ التالي تلقائياً. للإيقاف: `Ctrl + C`.

بديل سريع بلا Node.js: افتحي `beauty/index.html` بالمتصفّح مباشرة — يعمل العرض، لكنك لن
تحصلي على رابط يفتح من الهاتف.

## النشر

المتجر يُنشر مع باقي المشروع على Firebase Hosting، على المسار `/beauty`:

| العنوان | المحتوى |
| --- | --- |
| `https://<اسم-المشروع>.web.app/` | تطبيق حرفة برو |
| `https://<اسم-المشروع>.web.app/albacha` | موقع مؤسسة الباشة للمعادن |
| `https://<اسم-المشروع>.web.app/beauty` | متجر الجمال |

`npm run build` ينسخ محتوى هذا المجلد تلقائياً إلى `dist/beauty` عبر `copy-to-dist.mjs`،
و`firebase.json` يحوي إعادة توجيه `/beauty` ← `/beauty/index.html`. ثم:

```bash
npm run deploy
```

تفاصيل إعداد Firebase والنشر عبر GitHub Actions في [`site/README.md`](../site/README.md) —
الإعداد نفسه يخدم المواقع الثلاثة.

### لجعل المتجر في جذر النطاق بدل `/beauty`

في `beauty/copy-to-dist.mjs` اجعلي `DEST_DIR = ''`، واحذفي إعادة توجيه `/beauty` من
`firebase.json`.

## ملاحظات

- **الطلبات تصل عبر واتساب فقط.** لا يوجد خادم ولا قاعدة بيانات: زرّ «إتمام الطلب» يفتح
  واتساب برسالة جاهزة تحوي المنتجات والكميات والإجمالي، والزبونة تضغط إرسال. تأكّدي من
  صحّة `phone` وإلا كانت أزرار الطلب معطّلة.
- **السلة محفوظة في متصفّح الزائرة** (`localStorage`)، فلا تصل إليكِ ولا تُشارَك بين
  الأجهزة. في التصفّح الخاص قد يمنع المتصفّح الحفظ، فتعمل السلة في الذاكرة حتى إغلاق
  الصفحة — وهذا متوقّع.
- **الأسعار تُكتب أرقاماً فقط** في `price`، والعملة تأتي من `STORE.currency` مرّة واحدة.
- **الخطوط** (Cairo و Playfair Display) تُحمَّل من Google Fonts، فبدون إنترنت يعمل الموقع
  بخطوط النظام الاحتياطية.
- **إطارات تيك توك وانستقرام** تُحمَّل من المنصّتين، وقد لا تظهر إن كان الفيديو خاصاً أو
  محذوفاً أو كان المتصفّح يحجب المحتوى الخارجي. زرّ «شاهدي على…» يبقى بديلاً يعمل دائماً.
- **تثبيت المتجر كتطبيق (PWA)** غير مُهيّأ هنا. لإضافته انسخي `manifest.webmanifest`
  و`sw.js` و`icons/` من مجلد `site/` وعدّلي الأسماء والألوان — الطريقة موصوفة في
  [`site/README.md`](../site/README.md).

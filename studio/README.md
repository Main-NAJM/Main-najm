# استوديو بوفايدة — أداة العمل الخاصّة

المكان الذي يُجهَّز فيه كل فيديو **قبل** توليده: السيناريو، نصّ التعليق الصوتي،
موجّهات المشاهد بالإنجليزية، نصّ المنشور، ثم المشاريع والسعر.

ملف واحد مستقلّ (`index.html`) — لا بناء ولا حزم ولا خادم.

## التشغيل محلياً

```bash
npm run studio
```

## ما تفعله الأداة وما لا تفعله

**تفعل:** تكتب لك ما تُطعمه لأداة التوليد — الموجّه الدقيق لكل مشهد، بالمفردات
البصرية التي تفهمها هذه الأدوات، وبمقاس الشاشة الصحيح.

**لا تفعل:** لا تولّد الصورة ولا الفيديو بنفسها. التوليد يحتاج خدمة مدفوعة ومفتاحاً،
والأداة هنا لا تتّصل بشبكة أصلاً. انسخ الموجّه والصقه في الأداة التي تشتغل بها.

> إن اشتركتَ يوماً في خدمة توليد، يُضاف الاتّصال بها في وحدة واحدة داخل هذا الملف —
> لأن كل المخرجات مبنية أصلاً على الشكل الذي تطلبه تلك الخدمات.

## الخصوصية — اقرأ هذا

الصفحة منشورة على GitHub Pages، أي أن **من يعرف رابطها يفتحها**. رمز الدخول فيها
**ستار لا قفل**: يخفيها عن المتطفّل ولا يمنع من يعرف كيف يقرأ شيفرة صفحة.

ما يحميها فعلاً أنها:

- غير مربوطة من أي صفحة (`/bofaida/` لا يشير إليها، ولا الموقع في الجذر)
- تحمل `noindex, nofollow` فلا تدخل نتائج البحث
- لا ترسل شيئاً إلى أي خادم — كل ما تكتبه يبقى في متصفّحك

**فلا تكتب فيها ما لا تحتمل أن يُرى**: لا كلمات مرور، ولا أرقام حسابات، ولا ما يخصّ
زبوناً ولا يخصّك.

## التخزين

كل شيء في `localStorage` تحت المفتاح `bofaida.studio.v1`. هذا يعني:

- يبقى في هذا المتصفّح وحده — لا يتزامن مع هاتف آخر
- مسح بيانات الموقع يمحوه
- **خذ نسخة احتياطية** من تبويب «الإعدادات» (ملف JSON) واحفظها في مكان آمن

## الأيقونات

```bash
pip install pillow
python3 studio/icons/generate-icons.py
```

شرارة كبيرة وشرارتان صغيرتان — تختلف عن أيقونة الموقع (مثلّث التشغيل) عمداً،
فالاثنتان تجلسان في شاشة واحدة على الهاتف.

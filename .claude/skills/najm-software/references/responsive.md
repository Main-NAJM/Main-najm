العقد: يعمل من **320px إلى 2560px**، بلا تمرير أفقي، بلا عنصر مقصوص أو متراكب، في الوضعين
الفاتح والداكن، وفي الاتجاهين الرأسي والأفقي، وباللغة العربية RTL.

## 1. نقاط الانكسار

أربع فقط. الزيادة عليها تُنتج نظامًا لا يمكن صيانته.

```css
/* الأساس: جوال. اكتب تخطيط الجوال أولًا بلا استعلام. */
--bp-sm:  480px;   /* جوال كبير أفقيًا / جوال عريض */
--bp-md:  768px;   /* لوحي رأسي */
--bp-lg: 1024px;   /* لوحي أفقي / حاسوب محمول صغير */
--bp-xl: 1280px;   /* حاسوب مكتبي */
```

**الجوال أولًا دائمًا.** التخطيط الأساسي بلا `@media`، والاستعلامات تضيف فقط بـ `min-width`.
البناء من الحاسوب نزولًا يُنتج شلالًا من `max-width` يتعارض ويستحيل تتبّعه.

**استعلامات الحاوية للمكوّنات.** المكوّن لا يعرف عرض الشاشة، بل عرض حاويته — البطاقة نفسها
قد تكون في عمود ضيّق أو شبكة عريضة:

```css
.card-host { container-type: inline-size; }
@container (min-width: 380px) { .card { grid-template-columns: auto 1fr; } }
```

استخدمها لكل مكوّن قابل لإعادة الاستعمال. استعلامات الوسائط للتخطيط العام فقط.

## 2. مصفوفة الأجهزة الملزِمة

لا يُعلَن اكتمال واجهة قبل فحصها على هذه العروض:

| العرض | الجهاز | ما يُفحَص |
| --- | --- | --- |
| **320px** | iPhone SE (الجيل الأول) / أصغر جهاز واقعي | لا تمرير أفقي، لا نص مقطوع، الأزرار تسع نصّها |
| **375px** | iPhone SE 2/3, iPhone 13 mini | التخطيط الأساسي |
| **390px** | iPhone 14/15/16 | الأكثر شيوعًا — اجعله مرجعك البصري |
| **430px** | iPhone Pro Max | لا تتمدّد العناصر تمدّدًا قبيحًا |
| **768px** | iPad رأسي | نقطة تحوّل: عمود ← عمودان |
| **1024px** | iPad أفقي / MacBook Air | تنقّل جانبي بدل سفلي |
| **1280px** | حاسوب مكتبي | حدّ أقصى للمحتوى — لا تمتدّ الأسطر بلا نهاية |
| **1920px+** | شاشة كبيرة | المحتوى متمركز ومقيَّد، لا صحراء بيضاء |

وأضف حالتين لا تُنسيان:

- **الجوال أفقيًا (مثلًا 844×390)** — الارتفاع 390px فقط. الأوراق والحوارات يجب أن تُمرَّر
  داخليًا لا أن تُقَصّ.
- **تكبير النص 200%** في إعدادات الجهاز — التخطيط يتمدّد ولا ينكسر.

## 3. القياس السائل

`clamp()` بدل سلالم نقاط الانكسار. الصيغة: `clamp(الأدنى, الأساس + معامل vw, الأقصى)`.

```css
/* حجم النص */
font-size: clamp(0.9375rem, 0.9rem + 0.2vw, 1rem);

/* الحشو الخارجي للصفحة — يكبر مع الشاشة */
padding-inline: clamp(1rem, 0.5rem + 2.5vw, 2.5rem);

/* الفجوات في الشبكة */
gap: clamp(0.75rem, 0.5rem + 1vw, 1.5rem);
```

**احذر:** لا تستخدم `vw` وحدها في `clamp` بلا جزء `rem` ثابت — يكسر تكبير المتصفح
لمستخدمي ضعف البصر (النص لا يستجيب لـ Ctrl+Plus).

## 4. التخطيط

**الشبكة التلقائية تغني عن معظم نقاط الانكسار:**

```css
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(280px, 100%), 1fr));
  gap: clamp(0.75rem, 2vw, 1.5rem);
}
```

`min(280px, 100%)` ضرورية: بدونها يفيض العنصر على شاشة أضيق من 280px.

**Flexbox مع `wrap` وأساس مرن:**

```css
.row { display: flex; flex-wrap: wrap; gap: 12px; }
.row > * { flex: 1 1 min(220px, 100%); }
```

**الفيضان — السبب الأول للتمرير الأفقي.** عنصر Flex/Grid لا ينكمش دون محتواه افتراضيًا.
كل حاوية تضمّ نصًا قد يطول:

```css
min-width: 0;          /* يسمح للعنصر بالانكماش */
overflow-wrap: anywhere; /* يكسر الكلمات الطويلة (روابط، أكواد) */
```

**الحدّ الأقصى للمحتوى.** `max-width` بـ `ch` للنص (68ch) وبـ `px` للتخطيط (1280px)، مع
`margin-inline: auto`. الشاشة العريضة بلا حدّ تُنتج أسطرًا لا تُقرأ.

**القصّ بلطف عند الضرورة:**

```css
overflow: hidden; text-overflow: ellipsis; white-space: nowrap; /* سطر واحد */
/* أو لأسطر متعددة: */
display: -webkit-box; -webkit-line-clamp: 2; -webkit-box-orient: vertical; overflow: hidden;
```

## 5. الوحدات

| استخدم | لا تستخدم | السبب |
| --- | --- | --- |
| `dvh` / `svh` / `lvh` | `vh` | شريط المتصفح في الجوال يتقلّص ويتمدّد؛ `100vh` يُنتج قفزة وقصًّا |
| `rem` للنص | `px` للنص | يحترم إعداد حجم الخط عند المستخدم |
| `px` للحدود والظلال | `rem` | الحدّ 1px يجب أن يبقى 1px |
| `%` / `fr` / `minmax` | عرض ثابت بـ `px` | العرض الثابت هو سبب التمرير الأفقي الأول |
| `ch` لعرض النص | `px` | يتبع الخط الفعلي |
| `env(safe-area-inset-*)` | قيم ثابتة للحواف | الأجهزة تختلف |

**الاستثناء الوحيد للعرض الثابت:** الأيقونات والصور المصغّرة. وحتى هذه تُكتب بـ
`flex-shrink: 0` كي لا تنضغط.

## 6. المناطق الآمنة والنتوء

المستند يحتاج أولًا:

```html
<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover" />
```

(موجود في `index.html` في هذا المستودع — لا تحذفه.)

ثم كل عنصر ملتصق بحافة:

```css
/* شريط سفلي ثابت */
.bottom-bar {
  padding-block-end: calc(12px + env(safe-area-inset-bottom));
}
/* شريط علوي ثابت */
.top-bar {
  padding-block-start: calc(12px + env(safe-area-inset-top));
}
/* محتوى ممتد بعرض الشاشة */
.page {
  padding-inline: calc(16px + env(safe-area-inset-left));
}
```

نسيانها يعني زرًّا تحت شريط الصفحة الرئيسية في آيفون — لا يُضغط أبدًا.

**لوحة المفاتيح على الجوال.** عند فتحها ينكمش `dvh`. الحقل النشط يجب أن يبقى مرئيًا:
استخدم `scrollIntoView({ block: 'center' })` عند `focus`، ولا تجعل زر الحفظ مثبّتًا بشكل
يختفي خلف لوحة المفاتيح.

## 7. RTL والخصائص المنطقية

التطبيق عربي. الخصائص الاتجاهية الصريحة خطأ افتراضي — تنقلب معكوسة أو لا تنقلب أصلًا.

| بدل | اكتب |
| --- | --- |
| `margin-left` / `margin-right` | `margin-inline-start` / `margin-inline-end` |
| `padding-left` / `padding-right` | `padding-inline-start` / `padding-inline-end` |
| `left` / `right` | `inset-inline-start` / `inset-inline-end` |
| `text-align: left` | `text-align: start` |
| `border-left` | `border-inline-start` |
| `border-radius: 8px 0 0 8px` | `border-start-start-radius` … أو `border-radius: 8px 0 0 8px / logical` |
| `width` / `height` | `inline-size` / `block-size` (اختياري لكن أنظف) |

**استثناءات مشروعة:** الظلال (`box-shadow`) والتدرّجات وتحويلات `translateX` لأثر بصري
محايد الاتجاه — لكن راجعها بصريًا في RTL قبل التسليم؛ السهم المتحرّك يجب أن يشير للجهة الصحيحة.

**الأيقونات الاتجاهية تنقلب:** سهم الرجوع، سهم «التالي»، أيقونة الإرسال. أما الأيقونات
المحايدة (تقويم، إعدادات، مستخدم) فلا. ولا تنقلب الأرقام ولا الشعارات ولا الرسوم البيانية
ذات المحور الزمني بلا تفكير.

## 8. التكيّف لا مجرّد التمدّد

الفرق بين واجهة متجاوبة وواجهة احترافية: الثانية تُعيد التفكير في التخطيط، لا تكبّره فقط.

| النمط | جوال | لوحي | حاسوب |
| --- | --- | --- | --- |
| **التنقّل** | شريط سفلي (إبهام) | شريط سفلي أو جانبي مصغّر | شريط جانبي كامل بنصوص |
| **القوائم** | بطاقة لكل عنصر، صف واحد | شبكة عمودين | جدول بأعمدة |
| **التفاصيل** | صفحة كاملة (دفع) | ورقة جانبية | لوحان: قائمة + تفصيل |
| **النماذج** | حقل لكل سطر | حقلان بالسطر للمرتبط | أعمدة منطقية + تسميات جانبية |
| **الأفعال** | ورقة سفلية (bottom sheet) | ورقة أو منبثقة | قائمة منسدلة عند الزر |
| **البحث** | أيقونة تفتح حقلًا | حقل في الشريط | حقل دائم + مرشّحات ظاهرة |

**قاعدة الإبهام.** على الجوال، الأفعال الأساسية في الثلث السفلي من الشاشة. الزرّ في الأعلى
يتطلّب إعادة إمساك الهاتف — عائق حقيقي على الشاشات الكبيرة.

**الجدول على الجوال** لا يُمرَّر أفقيًا ولا يُصغَّر خطّه. يتحوّل إلى بطاقات: كل صف بطاقة،
وكل عمود سطر «تسمية: قيمة».

## 9. الصور والوسائط

```html
<img src="…" width="800" height="600"
     style="aspect-ratio: 4/3; inline-size: 100%; block-size: auto; object-fit: cover;"
     loading="lazy" decoding="async" alt="وصف بالعربية" />
```

- **`width`/`height` أو `aspect-ratio` إلزاميان** — يحجزان المساحة ويمنعان قفزة التخطيط.
- **`object-fit: cover`** مع نسبة محجوزة بدل ترك الصورة تفرض ارتفاعها.
- **`srcset`/`sizes`** للصور الكبيرة — تحميل صورة 2400px على جوال هدر واضح.
- **`loading="lazy"`** لكل صورة خارج الشاشة الأولى، **لا** للصورة الأولى المرئية.
- **`alt` بالعربية** ووصفيّ. الصورة الزخرفية البحتة تأخذ `alt=""`.

## 10. الاختبار

قبل إعلان الانتهاء، فعليًا لا افتراضًا:

```bash
bash .claude/skills/najm-software/scripts/quality-gate.sh
```

ثم يدويًا في المتصفح (DevTools → Device Toolbar):

- [ ] **320px** — لا تمرير أفقي. تحقّق بـ `document.documentElement.scrollWidth <= window.innerWidth`
- [ ] **390px** — المرجع البصري: كل شيء مريح وغير مزدحم
- [ ] **768px** و**1024px** — التخطيط يتكيّف فعلًا (لا مجرّد تمدّد)
- [ ] **1920px** — المحتوى مقيَّد ومتمركز
- [ ] **جوال أفقيًا** — الأوراق والحوارات تُمرَّر داخليًا
- [ ] **الوضع الداكن** — كل شاشة، لا انعكاس آلي
- [ ] **تكبير 200%** — لا انكسار
- [ ] **لوحة المفاتيح مفتوحة** — الحقل النشط وزر الحفظ مرئيان
- [ ] **RTL** — الأسهم والهوامش والزوايا في جهتها الصحيحة

فحص سريع للتمرير الأفقي في وحدة التحكّم — يطبع العنصر المذنب:

```js
[...document.querySelectorAll('*')].filter(el =>
  el.getBoundingClientRect().right > document.documentElement.clientWidth + 1
);
```

# موقع مؤسسة الباشة للمعادن — تشغيل محلي

موقع تعريفي من صفحة واحدة (`index.html`) لمؤسسة الباشة للمعادن — تيمياوين، ولاية برج باجي
مختار. الملف مستقل بالكامل: التنسيق والسكربت داخله، ولا يحتاج بناءً ولا حزماً.

## التشغيل

من جذر المستودع:

```bash
npm run site
```

أو مباشرة (يحتاج Node.js 18 أو أحدث فقط):

```bash
node site/serve.mjs
```

يطبع الأمر رابطين:

```
على هذا الجهاز:   http://localhost:8080
على الشبكة:        http://192.168.x.x:8080
```

- **رابط الجهاز** — افتحه في متصفّح الحاسوب نفسه.
- **رابط الشبكة** — افتحه من الهاتف أو من أي جهاز متصل بنفس شبكة الواي‑فاي، وهو الرابط
  الذي تشاركه مع من هو معك في نفس المكان لعرض الموقع قبل نشره على الإنترنت.

لتغيير المنفذ إن كان مشغولاً:

```bash
npm run site -- 3000
```

وإن كان المنفذ المطلوب مشغولاً يجرّب الخادم المنفذ التالي تلقائياً حتى يجد منفذاً حراً.

للإيقاف: `Ctrl + C`.

## تثبيت الموقع كتطبيق (PWA)

الموقع مُهيّأ كتطبيق ويب تقدّمي: يُثبَّت على الشاشة الرئيسية بأيقونته الخاصة، ويفتح في نافذة
مستقلّة بلا شريط عنوان المتصفّح، ويعمل دون إنترنت بعد أول زيارة.

| الملف | الدور |
| --- | --- |
| `manifest.webmanifest` | اسم التطبيق وأيقونته وألوانه ووضع العرض المستقل |
| `sw.js` | عامل الخدمة — يخزّن الصفحة والأيقونات والخطوط للعمل دون اتصال |
| `icons/` | أيقونات 192 و512 ونسخة maskable لأندرويد وأيقونة iOS |

**شرط التثبيت:** أن يُفتح الموقع عبر `https://` (أي بعد نشره على Firebase) أو عبر
`http://localhost` أثناء التطوير. رابط الشبكة المحلية `http://192.168.x.x` يعرض الموقع لكنه
لا يسمح بالتثبيت لأن المتصفّحات تشترط اتصالاً آمناً.

**طريقة التثبيت بعد النشر:**

- **أندرويد (Chrome):** افتح الرابط ← قائمة ⋮ ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- **iPhone (Safari):** افتح الرابط ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **الحاسوب (Chrome/Edge):** أيقونة التثبيت في شريط العنوان.

**تعديل الأيقونة:** الأيقونات مولَّدة برمجياً من `icons/generate-icons.py` (رمز باب مقوّس
بألوان الموقع). لتغييرها عدّل السكربت وأعد تشغيله:

```bash
pip install pillow
python3 site/icons/generate-icons.py
```

أو ضع صورك مباشرة مكان ملفات PNG بنفس الأسماء والأحجام.

**عند تعديل الموقع بعد النشر:** ارفع رقم `VERSION` في `sw.js` حتى تصل النسخة الجديدة لمن
ثبّتوا التطبيق سابقاً.

## النشر على Firebase Hosting

الموقع يُنشر مع تطبيق حرفة برو في نفس المشروع، على المسار `/albacha`:

| العنوان | المحتوى |
| --- | --- |
| `https://<اسم-المشروع>.web.app/` | تطبيق حرفة برو |
| `https://<اسم-المشروع>.web.app/albacha` | موقع مؤسسة الباشة للمعادن |

`npm run build` ينسخ محتوى هذا المجلد تلقائياً إلى `dist/albacha` عبر `copy-to-dist.mjs`،
و`firebase.json` يحوي إعادة توجيه `/albacha` ← `/albacha/index.html` قبل إعادة توجيه التطبيق.

### الطريقة الأولى: من جهازك بأمر واحد

```bash
npm run deploy -- --project <اسم-مشروعك-على-Firebase>
```

في أول مرة فقط: `npx firebase-tools@13 login`. الأمر يبني التطبيق والموقع ثم ينشرهما معاً.

### الطريقة الثانية: تلقائياً عبر GitHub Actions

سير العمل `.github/workflows/deploy-firebase.yml` جاهز، ويحتاج إضافة سرّين من
**Settings ← Secrets and variables ← Actions**:

| السرّ | القيمة |
| --- | --- |
| `FIREBASE_PROJECT_ID` | معرّف مشروعك على Firebase |
| `FIREBASE_SERVICE_ACCOUNT` | محتوى مفتاح حساب الخدمة (JSON) من Project settings ← Service accounts |

بعدها يتم النشر عند كل دمج في `main`، أو يدوياً من تبويب **Actions ← نشر على Firebase Hosting**.

### لجعل الموقع في جذر النطاق بدل `/albacha`

في `site/copy-to-dist.mjs` اجعل `DEST_DIR = ''`، واحذف إعادة توجيه `/albacha` من
`firebase.json`. عندها يحلّ الموقع التعريفي محلّ تطبيق حرفة برو في الصفحة الرئيسية.

## هل أحتاج ملف APK؟

تثبيت PWA يكفي في الغالب: أيقونة على الشاشة، نافذة مستقلّة، عمل دون إنترنت، وتحديث فوري
عند كل نشر بلا مراجعة من أحد. أما ملف APK على Google Play فيلزم فقط إذا أردت وجود التطبيق
في المتجر نفسه. الطريق إليه من هنا قصير لأن الموقع صار PWA صالحاً:

```bash
npx @bubblewrap/cli init --manifest https://<اسم-المشروع>.web.app/albacha/manifest.webmanifest
npx @bubblewrap/cli build
```

يولّد ذلك تطبيق **TWA** يعرض الموقع نفسه داخل تطبيق أندرويد. يحتاج إضافةً: تثبيت JDK و
Android SDK على جهازك، ومفتاح توقيع تحتفظ به، وحساب مطوّر على Google Play (رسم تسجيل
لمرّة واحدة)، وملف `assetlinks.json` على الاستضافة لإخفاء شريط العنوان.

## ملاحظات

- الخطوط (El Messiri و IBM Plex Sans Arabic) تُحمَّل من Google Fonts، فبدون إنترنت يعمل
  الموقع بخطوط النظام الاحتياطية.
- رابط الشبكة يعمل داخل الشبكة المحلية فقط ولا يصل إليه أحد من خارجها. لنشر الموقع على
  الإنترنت بعنوان عام تُستخدم استضافة مثل Firebase Hosting أو GitHub Pages.
- بديل سريع بدون Node.js: افتح `site/index.html` بالمتصفّح مباشرة — يعمل العرض، لكنك لن
  تحصل على رابط يفتح من الهاتف.

# تطبيق مؤسسة الباشة للمعادن — إدارة الزبائن والطلبات

تطبيق ويب مستقلّ لإدارة عمل المؤسسة اليومي: سجلّ الزبائن، عروض الأسعار والطلبات بقياساتها،
الدفعات والمستحقّات، وطباعة عرض السعر والفاتورة بتنسيق A4 عربي.

يعمل على الهاتف والحاسوب من نفس الشيفرة، ويُثبَّت كتطبيق على الشاشة الرئيسية، ويعمل دون
إنترنت.

---

## ما يفعله

| القسم | الوظائف |
| --- | --- |
| **الرئيسية** | عدد الزبائن، الطلبات قيد التنفيذ، إجمالي المستحقّ، الطلبات المتأخّرة عن موعد التسليم، وآخر الطلبات |
| **الزبائن** | إضافة وتعديل وحذف، بحث بالاسم أو الهاتف، اتصال وواتساب بضغطة، ورصيد كل زبون |
| **الطلبات** | عرض سعر أو طلب، بنود بالقياس (عرض × ارتفاع × العدد) أو بالقطعة، أجرة تركيب وخصم، حالات (عرض سعر / قيد التنفيذ / جاهز / مركّب / ملغى)، تصفية وبحث |
| **الدفعات** | تسجيل دفعات جزئية بتاريخها وملاحظتها، وحساب الباقي تلقائياً |
| **المستحقّات** | المبالغ غير المسدَّدة مجمّعة حسب الزبون، مع تذكير جاهز عبر واتساب |
| **الطباعة** | عرض سعر أو فاتورة بترويسة المؤسسة وجدول البنود والمساحات والإجماليات |
| **الإعدادات** | بيانات المؤسسة على المستندات، العملة، وتصدير/استيراد نسخة احتياطية JSON |

### طريقة التسعير

بند القياس يُحسب: **العرض × الارتفاع × العدد × سعر المتر المربّع**، وبند القطعة:
**العدد × سعر القطعة**. الإجمالي = مجموع البنود + أجرة التركيب − الخصم.

## التشغيل

من جذر المستودع:

```bash
npm install        # مرّة واحدة (يثبّت التطبيقين معاً — مساحات عمل npm)
npm run app        # يفتح على http://localhost:5180
```

بدون إعدادات Firebase يعمل التطبيق في **وضع الجهاز**: كل البيانات في المتصفّح، فيمكن
تجربته وإدخال بيانات حقيقية فوراً. لربط الحساب والمزامنة:

```bash
npx firebase-tools@13 login
npm run firebase:setup
```

ثم فعّل طرق الدخول الثلاث من الكونسول (تفاصيلها في README الجذر).

## البيانات في Firestore

```
users/{uid}                              ← الحقل albachaProfile: بيانات المؤسسة
users/{uid}/albachaCustomers/{id}        ← الزبائن
users/{uid}/albachaOrders/{id}           ← الطلبات، وبداخلها البنود والدفعات
```

أسماء المجموعات مسبوقة بـ `albacha` لأن نفس مشروع Firebase يستضيف تطبيق «حرفة برو» الذي
يستعمل `users/{uid}/orders` بمخطّط مختلف — فالفصل يمنع اختلاط البيانات. قواعد الأمان في
`firestore.rules` بجذر المستودع تسمح لكل مستخدم ببياناته وحدها.

## النشر

يُنشر مع بقية المشروع على مسار `/app`:

```bash
npm run deploy -- --project albacha-metals     # من جذر المستودع
```

| العنوان | المحتوى |
| --- | --- |
| `https://albacha-metals.web.app/` | تطبيق حرفة برو |
| `https://albacha-metals.web.app/albacha` | الموقع التعريفي |
| `https://albacha-metals.web.app/app` | **هذا التطبيق** |

`npm run build` في الجذر يبني الثلاثة وينسخها إلى `dist`. بعد النشر افتح `/app` من هاتفك
وثبّته: قائمة ⋮ ← «تثبيت التطبيق» في أندرويد، أو المشاركة ← «إضافة إلى الشاشة الرئيسية»
في iPhone.

عند تعديل التطبيق بعد النشر ارفع رقم `VERSION` في `public/sw.js` حتى تصل النسخة الجديدة
لمن ثبّتوه.

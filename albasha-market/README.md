# متجر الباشا — Albasha Market

موقع واجهة (storefront) للمتجر الرقمي على Payhip: صفحة واحدة ثنائية اللغة (عربي/إنجليزي)
بوضعين فاتح وداكن، تعرض المنتجات وتحوّل الزائر إلى صفحة الشراء على
[Payhip](https://payhip.com/Najmstars) لإتمام الدفع والتحميل.

الموقع **HTML و CSS و JavaScript خام** — بدون أدوات بناء ولا تبعيات. افتح `index.html`
في المتصفّح وستعمل الصفحة مباشرة.

---

## البنية

```
albasha-market/
├─ index.html              الصفحة الكاملة (الهيكل + وسوم SEO)
└─ assets/
   ├─ css/styles.css       نظام التصميم كاملاً (رموز الألوان، المكوّنات، الاستجابة)
   ├─ js/config.js         ★ روابط المتجر وبيانات التواصل
   ├─ js/products.js       ★ كتالوج المنتجات والفئات
   ├─ js/i18n.js           نصوص الواجهة بالعربية والإنجليزية
   ├─ js/app.js            منطق الصفحة (اللغة، السمة، البحث، التصفية، نافذة المنتج)
   └─ img/                 الأيقونة وصورة المشاركة
```

★ = الملفات التي ستعدّلها عادةً.

## إضافة منتجاتك الحقيقية

المنتجات الموجودة حالياً في `assets/js/products.js` **أمثلة توضيحية** لعرض شكل الموقع.
لاستبدالها بمنتجاتك:

1. افتح صفحة المنتج على Payhip وانسخ رابطها (مثل `https://payhip.com/b/XXXXX`).
2. افتح `assets/js/products.js` وأضف عنصراً بهذا الشكل:

```js
{
  id: 'my-product',            // معرّف فريد
  category: 'ebooks',          // يجب أن يطابق id في CATEGORIES
  url: 'https://payhip.com/b/XXXXX',
  price: 9,                    // 0 يعني «مجاناً»
  image: 'assets/img/my-product.jpg',   // اتركه '' لاستخدام الشكل البديل
  badge: { ar: 'الأكثر مبيعاً', en: 'Bestseller' },  // أو null
  name: { ar: 'اسم المنتج', en: 'Product name' },
  desc: { ar: 'وصف مختصر', en: 'Short description' },
  includes: [
    { ar: 'ملف PDF', en: 'PDF file' },
  ],
}
```

- أي منتج بلا `url` سيوجّه الزائر إلى صفحة المتجر الرئيسية.
- لإضافة فئة جديدة، أضفها إلى `CATEGORIES` في أعلى نفس الملف. الفئات التي لا تحتوي
  منتجات لا تظهر في شريط التصفية.
- الصور اختيارية؛ بدونها يعرض الموقع شكلاً بديلاً أنيقاً بأيقونة الفئة.

## تغيير الروابط وبيانات التواصل

كل شيء في `assets/js/config.js`:

```js
storeUrl: 'https://payhip.com/Najmstars',
currency: 'USD',                 // أو SAR أو AED …
contact: {
  email: 'you@example.com',
  whatsapp: '9647701234567',     // بالصيغة الدولية، بدون + أو مسافات
  instagram: 'https://instagram.com/…',
  // اترك أي حقل فارغاً ('') ليختفي رابطه من التذييل
}
```

زر «راسلنا» يستخدم أول قناة متاحة بالترتيب: واتساب ← البريد ← تيليغرام ← إنستغرام.

## تعديل النصوص

جميع نصوص الواجهة في `assets/js/i18n.js` داخل كائنين: `ar` و `en`. أي مفتاح تعدّله
يجب أن يبقى موجوداً في اللغتين.

## التشغيل محلياً


## النشر

الموقع ملفات ثابتة، فينشر على أي استضافة:

**Firebase Hosting** (المشروع مربوط بها أصلاً) — أضف هدفاً ثانياً في `firebase.json`
بجذر المستودع:

```json
"hosting": [
  { "target": "app", "public": "dist", "...": "إعدادات حرفة برو الحالية" },
  { "target": "market", "public": "albasha-market", "ignore": ["**/.*"] }
]
```

ثم:

```bash
firebase target:apply hosting market <اسم-الموقع-في-فايربيس>
firebase deploy --only hosting:market
```

**GitHub Pages** — سير العمل `.github/workflows/deploy-pages.yml` جاهز: يرفع محتوى
`albasha-market/` وحده (تطبيق حرفة برو لا يُنشر منه)، ويفعّل Pages تلقائياً في أول
تشغيل ناجح عبر `enablement: true`. يعمل عند الدفع إلى الفرع الافتراضي، أو يدوياً من
تبويب **Actions**. العنوان الناتج: `https://main-najm.github.io/Main-najm/`.

> ‏GitHub Pages على مستودع **خاص** يتطلّب خطة GitHub Pro أو أعلى. على الخطة المجانية
> لا تعمل إلا على المستودعات العامة.

**Netlify** — يعمل مع المستودعات الخاصة على الخطة المجانية. ملف `netlify.toml` في جذر
المستودع جاهز، فلا تحتاج ضبط شيء يدوياً:

> Add new site ← Import an existing project ← اختر المستودع ← Deploy

**Cloudflare Pages** — بديل مكافئ (لا يقرأ `netlify.toml`، فاضبط الحقلين يدوياً):

| الحقل | القيمة |
| --- | --- |
| Build command | *(اتركه فارغاً)* |
| Build output directory | `albasha-market` |

## ما هو مدعوم

- ثنائية اللغة كاملة مع تبديل اتجاه الصفحة (RTL ⇄ LTR) وحفظ الاختيار في المتصفّح.
- وضع فاتح وداكن، يتبع تفضيل النظام في أول زيارة ثم يحفظ اختيار الزائر.
- بحث فوري وتصفية حسب الفئة، ونافذة تفاصيل لكل منتج.
- إتاحة الوصول: روابط تخطٍّ، تباين مطابق لـ WCAG AA، أهداف لمس ‎44×44px، حلقات تركيز
  ظاهرة، واحترام `prefers-reduced-motion`.
- وسوم SEO و Open Graph وبيانات منظّمة (JSON-LD) من نوع `OnlineStore`.

## ملاحظة

الدفع والتسليم يتمّان بالكامل على Payhip؛ هذا الموقع واجهة عرض ولا يجمع أي بيانات
دفع أو بيانات شخصية، ولا يستخدم أي خدمات تتبّع.
